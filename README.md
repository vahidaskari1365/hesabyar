# حساب‌یار هوشمند — نرم‌افزار حسابداری مبتنی بر هوش مصنوعی و اتوماسیون

نرم‌افزار حسابداری اختصاصی برای نیازهای ایرانی، با رابط کاملاً فارسی (RTL)، گزارش‌های گرافیکی و تعاملی، گزارش‌ساز، تحلیل هوش مصنوعی و موتور اجرای فرآیندها (اتوماسیون).

## ✨ امکانات

- **داشبورد مالی** — شاخص‌های کلیدی، روند درآمد/هزینه/سود، تفکیک هزینه‌ها و دارایی‌ها، مشتریان برتر — همه کلیک‌پذیر
- **اسناد حسابداری** — ثبت سند با اعتبارسنجی تراز، گردش‌کار پیش‌نویس/قطعی، ثبت هوشمند با پیشنهاد هوش مصنوعی
- **اسکن هوشمند اسناد** — آپلود تصویر فاکتور/رسید و استخراج خودکار اطلاعات با AI (بینایی ماشین) + پیشنهاد سند
- **فاکتورها** — فاکتور فروش/خرید با تولید خودکار سند حسابداری دوطرفه و محاسبه مالیات ارزش افزوده
- **کدینگ حساب‌ها** — درخت حساب‌های استاندارد ایرانی با مانده تجمیعی، دفتر کل و گردش ماهانه هر حساب
- **طرف‌حساب‌ها** — مشتریان و تأمین‌کنندگان با مانده دریافتنی/پرداختنی زنده
- **گزارش‌های مالی گرافیکی** — تراز آزمایشی، سود و زیان، ترازنامه، دفتر کل، دفتر روزنامه + چاپ و خروجی CSV
- **گزارش‌ساز** — ساخت گزارش دلخواه (مجموعه‌داده × بعد × سنجه × نوع نمودار) و ذخیره گزارش‌ها
- **تحلیل هوشمند** — یافته‌ها، هشدارها و توصیه‌های خودکار بر اساس داده واقعی شرکت + دستیار گفتگویی
- **فرآیندها و اتوماسیون** — اجرای چرخه‌های حسابداری با یک کلیک:
  - بستن دوره مالی ماه (قطعی‌سازی اسناد + استهلاک + خلاصه دوره)
  - همگام‌سازی فاکتورها با اسناد (تولید خودکار سند)
  - پیگیری وصول مطالبات (دسته‌بندی سنی + توصیه اقدام)
  - ممیزی و کنترل صحت داده‌ها (تراز، تکرار، کدینگ، ارزش افزوده)
  - تحلیل هوشمند عملکرد مالی (شاخص‌ها + روند + توصیه‌ها)

## 🚀 اجرای سریع (بدون دیتابیس)

```bash
bun install
bun run dev
```

همین! نرم‌افزار به‌صورت پیش‌فرض در **حالت حافظه** بالا می‌آید — با داده نمونه واقع‌گرایانه (۱۱۲ سند، ۴۹ فاکتور، کدینگ استاندارد ایرانی) و **هیچ نیازی به نصب یا راه‌اندازی دیتابیس نیست**. تمام امکانات (ثبت، ویرایش، گزارش‌ها، فرآیندها) در این حالت فعال هستند؛ فقط داده‌ها با ری‌استارت سرور به حالت اولیه برمی‌گردند.

> برای بازگرداندن داده نمونه در هر لحظه: بخش «فرآیندها و اتوماسیون» ← «بازنشانی داده‌های نمونه»

## 🗄️ استفاده با دیتابیس (اختیاری — SQLite)

اگر می‌خواهید داده‌ها ماندگار باشند:

```bash
# ۱) فایل env بسازید
echo 'DATABASE_URL=file:./db/custom.db' > .env

# ۲) اسکیما را اعمال و داده اولیه بریزید
bun run db:push
bunx tsx prisma/seed.ts   # یا: bun prisma/seed.ts

# ۳) اجرا
bun run dev
```

برای اجبار به حالت حافظه حتی با وجود DATABASE_URL: متغیر محیطی `MEMORY_DB=1`

## 🎨 تم روشن/تاریک/سیستم

از دکمه خورشید/ماه در هدر یا بخش «تنظیمات» ← کارت «ظاهر» قابل انتخاب است.

## 🧰 تکنولوژی‌ها

- **Next.js 16** (App Router) + **TypeScript 5**
- **Tailwind CSS 4** + shadcn/ui (New York) + Lucide Icons
- **Recharts** برای نمودارهای فارسی RTL
- **Prisma** (SQLite) با **fallback حافظه‌ای خودکار**
- **Zustand** برای مدیریت وضعیت، **Sonner** برای اعلان‌ها
- **z-ai-web-dev-sdk** برای LLM/VLM (ثبت هوشمند، اسکن اسناد، تحلیل، دستیار)

## 📁 ساختار پروژه

```
src/
  app/api/            # API Routes: dashboard, entries, accounts, contacts,
                      # invoices, reports, report-builder, saved-reports,
                      # processes (موتور فرآیندها), ai/*, settings
  components/
    sections/         # ۱۱ بخش تک‌صفحه‌ای (SPA)
    shared/           # SectionShell, StatCard, ChartCard, SidebarNav, AIAssistant
    ui/               # کامپوننت‌های shadcn/ui
  lib/
    db.ts             # لایه داده با تعویض خودکار Prisma ↔ حافظه
    server/memory.ts  # موتور داده درون‌حافظه + داده نمونه
    server/accounting.ts  # محاسبات هسته حسابداری
prisma/               # اسکیما + seed (اختیاری)
```
